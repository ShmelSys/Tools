# 1. Vérifie ce que tu as modifié (Optionnel mais recommandé)
```git status```

# 2. Ajoute toutes tes modifications
```git add .```

# 3. Crée une sauvegarde avec un message expliquant ce que tu as fait
```git commit -m "Ajout de la fonction X" ou "Correction du bug Y"```

# 4. TRÈS IMPORTANT : Récupère le travail de ton ami avant d'envoyer le tien
```git pull```

# 5. Envoie ton travail fusionné sur GitHub
```git push```
